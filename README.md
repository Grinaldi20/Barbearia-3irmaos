# 💈 Barbearia 3 Irmãos

Landing page desenvolvida para a **Barbearia 3 Irmãos**, um negócio da cidade de Tupã/SP, com foco em apresentar os serviços da barbearia, facilitar o contato com os clientes e oferecer uma experiência moderna e responsiva.

## 🚀 Tecnologias utilizadas

* React.js
* Vite.js
* JavaScript
* HTML5
* CSS3

## ✨ Funcionalidades

* Página totalmente responsiva
* Apresentação dos serviços
* Seção sobre a barbearia
* Contato rápido via WhatsApp
* Navegação fluida entre as seções
* Interface moderna e intuitiva

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para atender a necessidade de um barbeiro da cidade de Tupã/SP, proporcionando uma presença digital profissional e facilitando o contato com seus clientes.

Além de entregar um site funcional, o projeto também serviu para aprimorar meus conhecimentos em React, componentização, organização de código e desenvolvimento de interfaces responsivas.
